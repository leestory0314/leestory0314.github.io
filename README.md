# LEESTORY

Static personal branding page for `www.leestory.com`.

## Files

- `index.html` — complete responsive site (CSS included)
- `assets/hero.jpg` — hero visual
- `.gitlab-ci.yml` — GitLab Pages deployment pipeline

## GitLab Pages

Push the contents of this folder to the root of your GitLab repository. The included pipeline copies the site into the GitLab Pages `public` artifact on the default branch.

## Custom domain

In GitLab, add `www.leestory.com` under **Deploy > Pages > New domain**, then configure the DNS record GitLab provides. Remove the existing `www -> blog.leestory.com` redirect after the Pages domain is verified.
